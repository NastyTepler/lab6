## Что реализовано
1. **Задание 1 (Рефлексия):** Создана аннотация `@Repeat`, которая принимает параметр `times`. Класс `MyClass` содержит публичные, защищенные и приватные методы, часть из которых аннотирована. Класс `Invoker` с помощью `java.lang.reflect` находит все методы с аннотацией, открывает к ним доступ (через `setAccessible(true)`), подготавливает аргументы и вызывает нужное количество раз.
2. **Задание 2 (java.nio.file):** Создана директория `Теплякова` с вложенной структурой `dir1/dir2/dir3`. Файлы копируются, выполняется рекурсивный обход с помощью `Files.walk` с выводом меток `D:` (директория) и `F:` (файл). В конце папка `dir1` со всем содержимым удаляется с использованием сортировки в обратном порядке.

## Инструкция по сборке и запуску
Проект собирается с помощью Maven.
1. Запустить программу: открыть класс `app.Main` и запустить метод `main`.
2. Или через терминал: `mvn clean compile exec:java -Dexec.mainClass="app.Main"` (если настроен плагин exec).
